# Dental Care Landing Page

A dental care landing page built based on a Figma design.

## Design

Figma: [Dental Care Landing Page](https://www.figma.com/design/97WhOC9ECHn68dftoSokSR/03.-Dental-Care-Landing-Page--Easy-?node-id=0-1&p=f&m=dev)

## Technologies

- HTML5
- CSS3

## Features

- Clean and modern user interface
- Dental care service layout
- Organized CSS styles
- Service showcase section
- Navigation and landing page sections

## Getting Started

1. Clone the repository.
   git clone https://github.com/tuongdp/dental-care-landing-page.git

2. Open the project folder in Visual Studio Code.
3. Open index.html in your browser or use the Live Server extension.

## Purpose

This project was created to practice converting a Figma design into a website using HTML and CSS.
